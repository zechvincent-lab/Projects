# Data Science & Analytics Projects Portfolio

This repository contains a collection of data science and analytics projects focused on forecasting, machine learning, and data-driven decision making.

The projects demonstrate end-to-end analytical workflows, including data preparation, exploratory data analysis, model development, evaluation, and interpretation of results in a business context.

## Overview

The work included in this portfolio explores a range of techniques across time series forecasting and data analysis, including:

* Classical statistical forecasting methods (e.g. decomposition, ARIMA)
* Machine learning approaches to prediction
* Deep learning models for time series forecasting
* Comparative evaluation of different modelling strategies
* Business-focused interpretation of results

## Projects Included

### 1. Book Sales Forecasting – *The Alchemist & The Very Hungry Caterpillar*

Time series forecasting analysis of two book sales datasets to identify trends, seasonality, and forecast future demand.

Key focus areas:

* Data cleaning and preprocessing
* Time series decomposition
* Stationarity testing
* ARIMA / statistical forecasting methods
* Model evaluation and comparison
* Inventory and demand forecasting insights

## Purpose of This Portfolio

The aim of this repository is to demonstrate practical data science skills applied to real-world inspired problems, with a focus on:

* Forecasting and predictive modelling
* Translating analysis into business insights
* Clear and reproducible workflows
* Communicating findings effectively
